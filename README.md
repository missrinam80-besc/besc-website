# BESC Website

Afzonderlijke private repository voor de eigen BESC-website. Command Center blijft eigenaar van inhoud en publicatiewerkstromen; de Discordbot heeft zijn eigen repository.

F2 is voorbereid en wacht op goedkeuring voor uitvoering. De staginglocatie is website-dev.belgianstreamerscommunity.be op BESCSRVDEV. De bestaande publieke website blijft staan.

Het [F2-pakket](docs/f2/README.md) bevat scope, acht werkpakketten, contracten, 69 geplande acceptatieproeven en het uitvoeringsmandaat. Er is nog geen website-app gebouwd of gedeployed. Server-/DNS-toegang en de concrete testerbinding zijn nog te controleren.
